## 1\. appLanguage 多语言资源管理工具

### 1\.1 项目概述

appLanguage 是一款面向 Android、iOS 双端项目的多语言资源文件管理工具，旨在解决移动端项目多语言文案管理混乱、Excel 文案与原生资源文件同步繁琐、文案合并整理效率低等问题，实现多语言资源的标准化、自动化管理。

### 1\.2 核心功能

- **资源文件转 Excel**：支持批量解析 Android、iOS 原生多语言资源文件，自动提取所有文案键值对，一键导出为标准化 Excel 表格，方便运营、产品人员查看与编辑文案。

- **Excel 转资源文件**：支持将编辑完成的 Excel 多语言文案表格，反向批量生成 Android、iOS 对应的原生多语言资源文件，适配双端资源文件格式规范，无需手动编写代码。

- **Excel 编辑内容合并同步**：支持将 Excel 中新增、修改、删除的文案内容，智能合并同步到项目原有资源文件中，自动比对新旧文案差异，保留有效原始内容，避免重复覆盖、文案丢失问题，完成资源文件的规整与更新。

### 1\.3 项目优势

大幅降低移动端多语言文案迭代的人工成本，规避手动修改资源文件导致的格式错误、文案遗漏、同步不一致等问题，适配项目持续迭代中的多语言更新场景。
